# www.woltanac.com

**Squirrel Sneak**: a browser stealth game built with Three.js. You play a squirrel getting into a woodland cabin using real squirrel entry routes: loose vents, branches to the roof, soffit gaps, uncapped chimneys, gnawed screens and wall voids.

- `/` is the game: `index.html`, `main.js`, `levels.js`. It is static, with no build step, and loads Three.js from a CDN via an import map.
- Five stealth levels plus a BONUS birdfeeder ninja obstacle course, which unlocks after level 5.
- Controls: WASD/arrows to move, Shift to sneak, Space to jump, C to climb, E to interact, Esc for the menu. Touch controls work on mobile.
- `/forest/` is the previous forest landing page, kept as is.
